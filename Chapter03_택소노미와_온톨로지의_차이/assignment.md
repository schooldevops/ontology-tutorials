## 과제 4. 온톨로지로 확장하기

과제 3의 택소노미를 온톨로지로 확장하세요.

아래 항목을 반드시 포함하세요.

### 클래스 계층

최소 6개 이상의 클래스를 `Is-A` 관계로 작성하세요.

예:

```text
Keyboard Is-A ComputerPeripheral
ComputerPeripheral Is-A PhysicalProduct
```

### 관계 속성

최소 5개 이상의 관계를 정의하세요.

예:

```text
compatibleWith
recommendedFor
availableWith
targets
hasConnectionType
```

각 관계마다 Domain과 Range를 작성하세요.

### 인스턴스 트리플

최소 12개의 트리플을 작성하세요.

형식:

```text
Subject | Predicate | Object
```
