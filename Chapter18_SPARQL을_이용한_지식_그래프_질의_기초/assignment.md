# 과제: SPARQL 질의문 작성

## 과제 개요

18강에서 배운 SPARQL의 트리플 패턴 매칭 구조를 활용하여, 비즈니스 시나리오에서 요구하는 조건에 맞는 질의문을 작성해 봅니다.

## 요구사항

1. **상황 분석:**
   마케팅 팀에서 다음 고객 리스트를 추출해 달라고 요청했습니다.
   - **타겟 고객 조건:**
     - 프리미엄 구독(Premium_Plan)을 이용 중인 상태(Active)이다.
     - 환불(RefundRequest) CS 티켓을 1번이라도 생성(raisedBy)한 적이 있다.

2. **SPARQL 구조 설계:**
   위 조건을 만족하기 위해 연결해야 할 노드(클래스/인스턴스)와 엣지(프로퍼티)는 다음과 같습니다.
   - `?user` (고객)
   - `?sub` (구독) : 상태가 "Active", 플랜 타입이 "Premium_Plan"
   - `?ticket` (티켓) : 유형이 "RefundRequest"

3. **SPARQL 쿼리문 작성:**
   요구사항을 충족하여 타겟 고객의 이름(`?userName`)과 이메일(`?email`)을 추출하는 SPARQL 쿼리를 작성하세요.
   - (단, 이메일은 입력되지 않은 고객도 있으므로, 이메일이 없는 고객도 리스트에 포함되도록 `OPTIONAL` 키워드를 사용하세요.)
   - PREFIX는 `PREFIX : <http://example.org/ontology/commerce#>` 로 가정합니다.

## 제출 형식

- 작성한 SPARQL 쿼리문을 Markdown 코드 블록(```sparql) 형태로 제출해 주세요.
- 질의문에 사용된 쿼리 패턴(각 라인)이 어떤 의미인지 짧은 주석(`#`)을 추가해 주세요.
